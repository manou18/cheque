# 🧾 عمّر الشاك — مساعد تعبئة صك بريد الجزائر (CCP)

أداة ويب مجانية، بصفحة واحدة (HTML/CSS/JS بدون أي تبعيات أو خطوة بناء)، تساعد على تحويل مبلغ مالي إلى حروف بثلاث لغات، ومعاينة صك بريد الجزائر قبل تعبئته، مع حاسبة لرسوم التحويل البريدي الرسمية.

**🔗 جرّبها مباشرة:** فعّل GitHub Pages لهذا المستودع (انظر قسم "النشر" أدناه) وستحصل على رابط مباشر.

## ✨ المزايا

- **تحويل المبلغ إلى حروف** بالعربية والفرنسية والإنجليزية، بالدينار أو بالسنتيم
- **إدخال صوتي** للمبلغ عبر المتصفح (Web Speech API)
- **معاينة صك حقيقي** لبريد الجزائر مع إمكانية **تصدير الصك كصورة JPG** جاهزة للطباعة أو المشاركة
- **حاسبة رسوم بريدية** رسمية (رسم ثابت + رسم متغيّر حسب الشريحة)
- **مفضلة** لحفظ مبالغ متكررة (إيجار، فواتير...) محليًا في المتصفح
- **وضع ليلي**، وتصميم متجاوب يعمل جيدًا على الهاتف
- **تعمل بالكامل بدون إنترنت** بعد أول تحميل (لا خادم خلفي ولا قاعدة بيانات) — البيانات لا تُرسل لأي مكان

## 🖥️ التشغيل محليًا

الملف صفحة واحدة، لا يحتاج أي تثبيت:

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
python3 -m http.server 8000
# ثم افتح http://localhost:8000 في المتصفح
```

> **لماذا خادم محلي وليس فتح الملف مباشرة؟**
> ميزة "تصدير الصك كصورة" تستخدم `<canvas>` لدمج النص فوق صورة الصك، والمتصفحات تمنع هذه العملية عند فتح الملف مباشرة من القرص (`file://`) لأسباب أمنية (CORS). باقي الميزات (التحويل إلى حروف، الحاسبة، المفضلة) تعمل حتى بفتح الملف مباشرة. **عند النشر عبر GitHub Pages هذا القيد يختفي تلقائيًا** لأن الموقع يُقدَّم عبر HTTPS.

## 🚀 النشر على GitHub Pages

1. ادفع (push) هذا المستودع إلى GitHub
2. من إعدادات المستودع: **Settings → Pages**
3. اختر المصدر (Source): **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`
4. احفظ، وانتظر دقيقة — سيظهر الرابط في نفس الصفحة بصيغة:
   `https://<username>.github.io/<repo>/`

لا حاجة لأي إعداد إضافي (لا Build، لا Actions) لأن المشروع HTML/CSS/JS خام بالكامل.

## 🛠️ التقنيات

HTML5, CSS3 (بدون أي إطار عمل)، JavaScript خام (Vanilla JS، بدون أي مكتبة خارجية) — باستثناء استيراد خط Cairo/Tajawal من Google Fonts. متصفح حديث فقط، لا حاجة لـ Node أو أي أداة بناء.

## ✅ الاختبارات

منطق تحويل الأرقام إلى حروف يحتوي مجموعة اختبارات انحدار مدمجة (بدون أي إطار اختبار خارجي). لتفعيلها وعرض نتائجها في console المتصفح:

```
index.html?selftest=1
```

## ⚠️ تنويه

هذه أداة مستقلة غير رسمية لتسهيل تعبئة الصكوك، وليست تابعة لبريد الجزائر (Algérie Poste) أو مرتبطة بها رسميًا. صورة نموذج الصك مستخدمة للتوضيح البصري فقط. تحقق دائمًا من صحة المبلغ والبيانات قبل توقيع أي صك حقيقي — الأداة لا تتحمل مسؤولية أي خطأ في التعبئة.
